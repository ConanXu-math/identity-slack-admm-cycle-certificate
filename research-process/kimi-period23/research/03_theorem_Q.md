# 定理 Q：齐次凸二次目标松弛三块 ADMM 的模式矩阵非扩张性

日期：2026-07-22。状态：**严格结论**（证明完整；数值核验 exp4）。

## 设定

问题（P）中 f, g 为凸二次型：f(x)=½x^TFx, g(y)=½y^TGy（F,G 对称 PSD，可为 0），
X,Y 全空间，b=0。子问题解唯一（若 F+βA^TA 奇异则取最小范数解，结论不变）。
此时 c ↦ Ax' 为线性映射：Ax' = −T_A c，T_A := βA(F+βA^TA)^{-1}A^T。
T_A 是对称 PSD 收缩（0 ⪯ T_A ⪯ I）：因为 T_A = q(A^TA 型) 或直接
v^TT_Av = β‖A^Tv‖²_{(F+βA^TA)^{-1}} ≤ ‖v‖²。同里 T_B。
**反之**，任意对称 PSD 收缩 T 都可由合法实例实现：取 A=T^{1/2}, F=β(I−T)
（则 βA(F+βA^TA)^{-1}A^T = βT^{1/2}(βI)^{-1}T^{1/2} = T）。
故"齐次凸二次类" ≡ "任意对称 PSD 收缩对 (T_A, T_B)"。

模式矩阵（固定符号模式 σ，D_± 同前）作用于 (p,t)：
  a = −T_A(p + D_+ t),  p' = −T_B(a + D_+ t),  t' = D_- t − a − p'.

## 定理 Q

对任意对称 PSD 收缩 T_A, T_B 与任意 0/1 对角 D_+，模式矩阵 M 的所有特征值 μ
满足 |μ| ≤ 1。

## 证明

设 (p,t)≠0，M(p,t)=μ(p,t)，|μ|>0，μ≠1。令 u := p + t。
由 t-方程：a = D_-t − μu。
  a + D_+t = t − μu ⟹ μp = −T_B(t−μu)，代入 p = u−t：
  (B') μ(I−T_B)u = (μI−T_B)t.
  −T_A(p+D_+t) = a = D_-t − μu，代入 p + D_+t = u − D_-t：
  (A') (μI−T_A)u = (I−T_A)D_-t.
设 |μ|>1。对对称 PSD 收缩 T 定义有理函数 φ(μ,T) := μ(μI−T)^{-1}(I−T)
（μI−T 可逆，因 spec(T)⊂[0,1]）。φ 是 T 的有理函数，正规，奇异值为
|q(s)|, q(s)=μ(1−s)/(μ−s), s∈spec(T)⊂[0,1]。
**引理**：|μ|>1, s∈[0,1] ⟹ |q(s)| ≤ 1。
  证：s=1 时 q=0。s∈[0,1) 时 |q(s)|≤1 ⟺ |μ|²(1−s)² ≤ |μ−s|² = |μ|²−2sReμ+s²
  ⟺ s[|μ|²(s−2)+2Reμ−s] ≤ 0 ⟸ 2Reμ ≤ |μ|²(2−s)+s。
  而 2Reμ ≤ 2|μ| < |μ|²+1 ≤ |μ|²(2−s)+s（末步 ⟺ (1−s)(|μ|²−1) ≥ 0）。∎
故 ‖φ(μ,T)‖ ≤ 1。
由 (A')：μu = φ(μ,T_A) D_- t；由 (B')：t = φ(μ,T_B) u。
合成：W u = μu，W := φ(μ,T_A) D_- φ(μ,T_B)。
但 ‖W‖ ≤ ‖φ_A‖·‖D_-‖·‖φ_B‖ ≤ 1，故 |μ| ≤ 1，矛盾。
（u≠0：否则 p=−t，(B') 给出 (μI−T_B)t=0，μ∉[0,1] 时 t=0，进而 (p,t)=0。）
μ∈{0,1} 本已满足。∎

## 推论（任意凸 f,g 的局部非排斥性）

对一般凸 f,g（不要求二次），记迭代映射 T_A^{it}(c) := A·argmin_x{f(x)+(β/2)‖Ax+c‖²}
（单值：Ax' 由二次项严格凸性唯一确定）。令 h(c) := min_x f(x)+(β/2)‖Ax+c‖²，
其共轭 h*(ξ)=f*(−A^Tξ)+(1/2β)‖ξ‖² 为 (1/β)-强凸 ⟹ h 为 β-光滑凸函数，
∇h(c)=β(Ax'(c)+c)，故 **−T_A^{it}(c) = c − (1/β)∇h(c)**，由 Baillon–Haddad
（β-光滑凸函数的梯度 β-余强制）知 **−T_A^{it} firmly nonexpansive**
（T_A^{it} 本身一般不是：f≡0 时 T_A^{it}=−P_A 反单调）。
在 ∇²h 存在的点（h 凸，Alexandrov 定理 ⟹ a.e.），∇T_A^{it}=(1/β)∇²h−I 对称、
特征值 ∈[−1,0]，即 **−∇T_A^{it} 为对称 PSD 收缩**。
线性化：δa = ∇T_A^{it}(c1*)·(δp+D_+δt) = −(−∇T_A^{it})(δp+D_+δt)，正是 (M_σ)
中以对称 PSD 收缩 −∇T_A^{it} 充任 "T_A" 的形式。由定理 Q：

**在任何 KKT 点处，若 h_A,h_B 于相应点二次可微且活跃集局部恒定（如严格互补），
则线性化迭代的所有模式矩阵谱半径 ≤1——CHYY 型局部几何排斥在松弛结构中不可能发生。**
（正则性假设的严格化见 research/04_proof_obligations.md 义务 O2。）

## 意义与边界

1. 在齐次二次类（含零目标、仿射集指示函数）中，任何固定符号锥内都不存在
   几何扩张方向 ⟹ CHYY 反例机制被 [A,B,I]+δ_+ 结构排除（对比：CHYY 中 C 非单位阵）。
2. b≠0 时迭代是仿射 v'=M_σ v+c_σ：若某锥内存在不动点（KKT 点），则该锥内轨道
   有界 ⟹ 若活动集最终稳定则收敛。**未闭合**：活动集是否必然稳定；切换轨道是否有界。
3. 非二次 f,g：局部结论（上述推论）；全局非线性分析未闭合（义务 O3）。
4. 因此：本问题若存在发散反例，必然依赖**跨模式切换**或**非线性全局机制**，
   而非 CHYY 型单锥几何扩张。这是严格划定边界的否定性结果。
