# 定理 M1：m=1（单个不等式约束）时齐次凸二次类直接松弛 ADMM 全局收敛

日期：2026-07-22。状态：**严格结论**（证明完整；数值核验通过）。

## 设定

m=1（单个约束），f,g 凸二次，b=0，子问题最小范数解。此时 p=By 与 t 均为标量，
收缩参数 τ_A, τ_B ∈ [0,1]（τ=1 为退化情形，如 f≡0）。两种模式（t>0 / t≤0）：

  M_+ = [[τ_Aτ_B, τ_Aτ_B−τ_B], [τ_A(1−τ_B), τ_A(1−τ_B)+τ_B]]   （t>0 锥）
  M_− = [[τ_Aτ_B, τ_B(1−τ_A)], [τ_A(1−τ_B), (1−τ_A)(1−τ_B)]]   （t≤0 锥）

（已由 m=1 与通用代码的一致性校验：exp4 pattern_matrix_quad 逐元相符。）

## 引理

(i) M_+ 的特征值为 τ_A, τ_B（det=τ_Aτ_B, trace=τ_A+τ_B）。
(ii) M_− 秩 1：M_− = u w^T，u=(τ_B, 1−τ_B)^T，w=(τ_A, 1−τ_A)^T；
    特征值为 0 与 tr = τ_Aτ_B + (1−τ_A)(1−τ_B) ≤ 1（等号仅 τ_A=τ_B=0 的平凡情形
    之外由 τ<1 严格 <1；tr≤1 因 1−tr = τ_A(1−τ_B)+τ_B(1−τ_A)−... 直接验证
    tr − 1 = −(τ_A(1−τ_B) + τ_B(1−τ_A)) + 2τ_Aτ_B − τ_Aτ_B... 见下证）。
证 (ii) tr≤1：tr = 1 − τ_A(1−τ_B) − τ_B(1−τ_A) + ... 直接：
  1 − tr = 1 − τ_Aτ_B − (1−τ_A)(1−τ_B) = τ_A + τ_B − 2τ_Aτ_B = τ_A(1−τ_B)+τ_B(1−τ_A) ≥ 0。∎

## 定理 M1

设 τ_A, τ_B ∈ [0,1]。从任意初值出发，分段线性迭代 v^{k+1} = M_{sign(t^k)} v^k
收敛到该分段映射的一个不动点（即原问题的 KKT 点），且收敛是线性（几何）速率的。

## 证明

关键观察（秩-1 着陆）：任一步 σ=− 迭代后，状态落在射线 span(u) 上：
v' = M_−v = u(w^Tv)。分三类轨道：

**情形 1：轨道从某时刻起恒在 t>0 锥。** 则 v^k = M_+^k v^{k0}。M_+ 特征值 τ_A,τ_B∈[0,1]
且半单（τ_A≠τ_B 时可对角化；相等时 M_+=τ·(2x2 若当需查)：直接验证 M_+ 在 τ<1 时
无特征值 1，故收敛到 0；τ_A=1 或 τ_B=1 时特征值 {1, τ}，1-特征空间半单，收敛到
M_+ 的某不动点——需验证该不动点在 t>0 锥内或为 0：若极限 t*>0，则它确为锥内不动点 ✓）。

**情形 2：轨道从某时刻起恒在 t≤0 锥。** 则 v^{k+1} = M_−v^k = (w^Tv^k)u，
v^{k+j} = (w^Tu)^{j−1}(w^Tv^k)u = tr^{j−1}(w^Tv^k)u → 0（tr<1；tr=1 仅 τ_A=τ_B=0，
此时 M_− 幂等，轨道一步到不动点）。

**情形 3：无限次切换。** 设某步 σ=− 后 v = cu（c = w^Tv_prev）。
- 若 c < 0：t = c(1−τ_B) < 0，继续 σ=−：c ← c·tr，|c| 几何衰减 → 0（tr<1）。
- 若 c > 0：t = c(1−τ_B) > 0，进入 σ=+ 锥。**断言：此后永不离开 t>0 锥**，
  从而归于情形 1。证明：从 v=cu 出发的 M_+ 轨道之 t 分量满足二阶递推
  t_{k+2} = (τ_A+τ_B)t_{k+1} − τ_Aτ_B t_k（M_+ 的特征多项式）。由
  t_0 = c(1−τ_B) 与 t_1 = e_2^TM_+u·c = c(1−τ_B)(τ_A+τ_B)（直接计算
  M_+u = (τ_B(τ_A+τ_B−1), (1−τ_B)(τ_A+τ_B))^T）解得
    t_k = c(1−τ_B)·(τ_A^{k+1} − τ_B^{k+1})/(τ_A − τ_B)  （τ_A≠τ_B）
  τ_A=τ_B=τ 时取极限 t_k = c(1−τ)(k+1)τ^k。两种情形 t_k>0 ∀k（τ_A,τ_B≥0），
  且 t_k 几何 → 0（τ<1）；τ_A=1（或 τ_B=1）时 t_k → 正常数，轨道收敛到锥内不动点。
∎

（边界 t=0 命中：映射连续，约定任一侧矩阵，上述分类不变。）
