## 1. 设置与符号

问题（P）：min f(x)+g(y)+δ_+(z) s.t. Ax+By+z=b；f=θ1+δ_X, g=θ2+δ_Y 适当闭凸。
L_β = f+g+δ_+ −⟨λ,r⟩+β/2‖r‖²，r=Ax+By+z−b。
直接三块 ADMM：x→y→z→λ（单位对偶步长）。
记 s^{k+1} := Ax^{k+1}+By^{k+1}−b（"无松弛残差"），r^{k+1}=s^{k+1}+z^{k+1}。

KKT（VI）解条件：∃(x*,y*,z*,λ*)：
−A^Tλ*∈∂f(x*), −B^Tλ*∈∂g(y*), −λ*∈∂δ_+(z*)（即 z*≥0, λ*≤0, ⟨z*,λ*⟩=0）, Ax*+By*+z*=b。

【2026-07-22 订正（符号约定）】上述 KKT 列表沿用幻灯片的 VI 写法（F(w)=(−A^Tλ,…)）。
而本算法（λ-更新 λ−βr，z-投影 max(λ/β−s,0)）的不动点实际满足
**A^Tλ*∈∂f(x*), B^Tλ*∈∂g(y*)**（λ*≤0 不变；对照原不等式问题，标准乘子 μ=−λ*≥0）。
对等式约束部分两种写法只差自由乘子整体符号，不影响 §2–§6 的任何推导
（推导中出现的只是 Δλ 与配对项）；但实验构造 KKT 点时必须用算法约定
（exp3 第一版曾因此误判，见日志）。以下 §2–§6 的代数全部直接由子问题最优性推出，
与该符号选择无关。
F(w)=(−A^Tλ,−B^Tλ,−λ,r)^T 是仿射斜对称算子：(w−w')^T(F(w)−F(w'))=0。

## 2. 子问题最优性条件（可直接核验的恒等式）

- z-子问题是投影：z^{k+1}=Π_{R^m_+}(λ^k/β − s^{k+1}) = max(t^k − s^{k+1} + min(t^k,0) − min(t^k,0)...)=max(λ^k/β−s^{k+1},0)。
- λ-更新代入 z-更新：λ^{k+1}=λ^k−β(s^{k+1}+z^{k+1})=β·min(λ^k/β−s^{k+1},0)（逐分量）。
- 推论（算法自动维持的性质，k≥1）：
  (a) z^k≥0, λ^k≤0（若 λ^0 不取正，k≥1 后总成立；其实只要 z^{k} 由投影产生）；
  (b) 互补性 ⟨z^k,λ^k⟩=0 精确成立（不要求收敛！）；
  (c) −λ^{k+1}∈∂δ_+(z^{k+1})。

## 3. 影子变量 t（关键化简）

定义 t^k := z^k + λ^k/β。由 2(a)(b)：z^k=max(t^k,0), λ^k/β=min(t^k,0)，即 t 的"正负分解"恰为 (z, λ/β)。
整个算法在状态 (y,t) 上封闭（无需单独记 z,λ）：

  x^{k+1} ∈ argmin_x f(x) + (β/2)‖Ax + By^k − b + |t^k|‖²          …(Tx)
  y^{k+1} ∈ argmin_y g(y) + (β/2)‖By + Ax^{k+1} − b + |t^k|‖²      …(Ty)
  t^{k+1} = min(t^k,0) − (Ax^{k+1}+By^{k+1}−b)                      …(Tt)

推导依据：x-子问题配平方 z^k−λ^k/β=|t^k|；t^{k+1}=λ^k/β−s^{k+1} 由定义即得。
正交分解恒等式（Pythagoras）：对任意 t',t''（分量正负支集不相交）：
  ‖max(t',0)−max(t'',0)‖² + ‖min(t',0)−min(t'',0)‖² = ‖t'−t''‖²。
特别地 β‖z^k−z*‖²+(1/β)‖λ^k−λ*‖² = β‖t^k−t*‖²。
固定点 ⟺ KKT 点（已验证：t'=t ⇒ z=max(t,0)=−s 即可行，且由子问题最优性得对偶可行）。

意义：算法是一个 (y,t) 上的分段（逐分量按符号）映射；λ-非正锥约束被精确吸收进 t 动力学。

## 4. 统一框架 VI 推导与标准证明的断点

子问题 VI（用 λ^{k+1}=λ^k−βr^{k+1} 改写，逐步可核验）：
(VI-x) f(x)−f(x^{k+1})+(x−x^{k+1})^T{−A^Tλ^{k+1}+βA^T[B(y^k−y^{k+1})+(z^k−z^{k+1})]} ≥ 0, ∀x
(VI-y) g(y)−g(y^{k+1})+(y−y^{k+1})^T{−B^Tλ^{k+1}+βB^T(z^k−z^{k+1})} ≥ 0, ∀y
(VI-z) δ_+(z)−δ_+(z^{k+1})+(z−z^{k+1})^T{−λ^{k+1}} ≥ 0, ∀z
(VI-λ) r^{k+1}+(1/β)(λ^{k+1}−λ^k)=0

四式相加，取 w=w*，用 F 斜对称性与 w* 最优性 ⇒（记 Δy=y^k−y^{k+1} 等）

  (1/β)(λ*−λ^{k+1})^T(λ^{k+1}−λ^k) ≥ β(x*−x^{k+1})^TA^T(BΔy+Δz) + β(y*−y^{k+1})^TB^TΔz.   …(★★)

候选 Lyapunov：V^k := β‖B(y^k−y*)‖² + β‖t^k−t*‖²（= β‖BΔ_y*‖²+β‖z^k−z*‖²+(1/β)‖λ^k−λ*‖²）。
展开 V^k−V^{k+1} 并代入 (★★)：
  V^k−V^{k+1} ≥ β‖BΔy‖²+β‖Δz‖²+(1/β)‖Δλ‖²
     + 2β(y^{k+1}−y*)^TB^TBΔy + 2β(z^{k+1}−z*)^TΔz
     + 2β(x*−x^{k+1})^TA^T(BΔy+Δz) + 2β(y*−y^{k+1})^TB^TΔz.   …(†)

两块情形（无 z）时右端为 β‖BΔy‖²+(1/β)‖Δλ‖²+2βΔy^TB^T[B(y^{k+1}−y*)+A(x*−x^{k+1})]，
经典证明（He 统一框架，借助预测量 \tildeλ=λ^k−β(Ax^{k+1}+By^k−b) 的预测-校正形式）可使其 ≥0。
三块直接推广的断点：含 Δz 的交叉项 2β(x*−x^{k+1})^TA^TΔz + 2β(z^{k+1}−z*+B(y*−y^{k+1}))^TΔz 无法定号——CHYY 反例正是利用这一点。
本问题的特殊资产（可能补救）：
  (S1) (Δz)^T(Δλ) ≤ 0（由 −λ∈∂δ_+(z) 的单调性/互补性）；
  (S2) z、λ/β 是 t 的正负分解，β‖Δz‖²+(1/β)‖Δλ‖²=β‖Δt‖²；
  (S3) λ^{k+1}/β = min(t^{k+1},0)，t↦min(t,0) 是到 R^m_- 的投影（firmly nonexpansive）。
未解决：上述资产是否足以让 (†) 右端 ≥ 曲率项？——目前既未证明也未否定。

## 5. 齐次零目标情形（反例狩猎场）

取 f≡0, g≡0, X=R^{n1}, Y=R^{n2}, b=0。子问题为最小二乘；规定取最小范数解（合法的选择方式）。
则 Ax^{k+1}=−P_A(By^k+max(t^k,0))，By^{k+1}=−P_B(Ax^{k+1}+max(t^k,0))，P_A,P_B 为正交投影。
迭代只依赖子空间对 (range A, range B) 与符号模式 σ=sign(t)：
状态 (p,t)∈range(B)×R^m（p=By）：
  a' = −P_A(p+t_+),  p' = −P_B(a'+t_+),  t' = t_- − a' − p'.
整个映射正齐次：Φ(αv)=αΦ(v), α>0。
⇒ 发散（某轨道/通有轨道几何增长）⟺ 存在符号模式 σ 使线性映射 M_σ 有特征值 |μ|>1 且对应特征向量的 t 分量符号与 σ 一致（自洽），此时轨道留在该锥内按 |μ| 几何放大。
⇒ 严格反例构造被归约为有限维代数问题：搜索子空间对 (U,V) 与自洽 (σ, μ, 特征向量)。
注：m=1 易验证只有 |μ|=1；P_A=P_B=I 时也只有 μ=1。扩张模必须来自退化秩与非平凡 σ（与 CHYY 用 R³ 中三个向量一致）。
