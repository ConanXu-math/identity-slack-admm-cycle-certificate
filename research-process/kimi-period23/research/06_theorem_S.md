# 定理 S：松弛三块 ADMM 模式矩阵的实特征值 ≤ 1

日期：2026-07-22。状态：**严格结论**（证明完整；数值核验 exp9 + 专项扫描）。
本文档取代 research/02、research/03（那两份因 |t| 线性化笔误，证明覆盖的是一个
不同——原始子问题缺乘子项——的算法，见 RESEARCH_LOG 更正条目）。

## 设定

齐次凸二次类：f, g 凸二次（含零），b=0，子问题解取最小范数最小二乘解。
迭代在状态 (p,t)（p=By∈range(B)，t=z+λ/β）上是正齐次分段线性映射；
固定符号模式 σ（D_+=diag(1[t_i>0])，D_−=I−D_+，J=D_+−D_−，|t|=Jt）后为线性映射

  a  = −T_A(p + Jt)
  p' = −T_B(a + Jt)
  t' = D_−t − a − p'                          (M_σ)

其中 T_A, T_B 为对称 PSD 收缩（0⪯T⪯I）：T_A=βA(F+βA^TA)^{-1}A^T（f=½x^TFx；f=0 时
T_A=P_{range A} 正交投影）。任意对称 PSD 收缩均可实现（A=T^{1/2}, F=β(I−T)）。

## 定理 S

对任意对称 PSD 收缩 T_A, T_B 与任意 0/1 对角 D_+，M_σ 的每个**实**特征值 μ
满足 μ ≤ 1。

## 证明

设 (p,t)≠0 为特征对，μ∉{0,1}（μ∈{0,1} 已满足）。记
  u := p + t,   t_+ := D_+t,   t_− := D_−t   （t = t_+ + t_−，⟨t_+,t_−⟩=0）。
由 t-方程 a = D_−t − μt − μp = t_− − μu。
又 p + Jt = (u − t) + (t_+ − t_−) = u − 2t_−，故
  (I1)  T_A(u − 2t_−) = μu − t_−.
又 a + Jt = (t_− − μu) + (t_+ − t_−) = t_+ − μu，而 μp = −T_B(a + Jt)，故
  (I2)  μ(u − t) = T_B(μu − t_+).
对对称 PSD 收缩 T 有 T² ⪯ T（T(I−T)⪰0），从而 ‖Tv‖² = ⟨T²v,v⟩ ≤ ⟨Tv,v⟩。
对 (I1) 用此式并代回 (I1)：
  ‖μu − t_−‖² = ‖T_A(u−2t_−)‖² ≤ ⟨T_A(u−2t_−), u−2t_−⟩ = ⟨μu − t_−, u − 2t_−⟩,
展开并消去 −2μ⟨u,t_−⟩：
  (X)  μ(μ−1)‖u‖² ≤ ‖t_−‖² − ⟨u, t_−⟩.
对 (I2) 同理：
  μ²‖u−t‖² = ‖T_B(μu−t_+)‖² ≤ ⟨T_B(μu−t_+), μu−t_+⟩ = μ⟨u−t, μu − t_+⟩,
整理（⟨u−t, t_+⟩ = ⟨u,t_+⟩ − ‖t_+‖²）：
  (Y)  μ‖t‖² − μ⟨u,t⟩ + ⟨u,t_+⟩ − ‖t_+‖² ≤ 0.
(X)+(Y)：用 ⟨u,t_−⟩+⟨u,t_+⟩=⟨u,t⟩ 与 ‖t_−‖²+‖t_+‖²=‖t‖²：
  μ(μ−1)‖u‖² + μ‖t‖² − μ⟨u,t⟩ + ⟨u,t⟩ − ‖t‖² ≤ 0
  ⟹ (μ−1)[μ‖u‖² + ‖t‖² − ⟨u,t⟩] ≤ 0.
设 μ>1，除以 μ−1：μ‖u‖² + ‖t‖² ≤ ⟨u,t⟩ ≤ ‖u‖·‖t‖。
但 AM–GM：μ‖u‖² + ‖t‖² ≥ 2√μ·‖u‖‖t‖，故 (2√μ−1)‖u‖‖t‖ ≤ 0。
μ>1 ⟹ 2√μ−1>0 ⟹ ‖u‖‖t‖=0。
- u=0：由 (I2)，T_B t_+ = μ t_+（因 u−t=−t 给出 −μt = −T_Bt_+），μ>1 与 T_B⪯I
  矛盾，除非 t_+=0；t_+=0 则 t=t_−，(I2) 给出 μt=0 ⟹ t=0 ⟹ (p,t)=0，矛盾。
- t=0：由 (I1)，T_A u = μu，μ>1 与 T_A⪯I 矛盾，除非 u=0，进而 (p,t)=0，矛盾。
故实特征值 μ>1 不存在。∎

## 注记

1. **复特征值可以 |μ|>1**（数值：20000 投影实例中 116 例）。但复特征值驱动轨道旋转，
   必然在有限步内越出当前符号锥——不能支撑"固定锥内几何扩张"。负实特征值同理（符号翻转）。
   ⟹ **CHYY 型单锥几何发散机制在本结构中被排除**（严格结论）。
2. 数值核验：exp9（30000 实例 × 742752 模式）：实 μ>1 计数 0；专项扫描：投影类
   20000 实例 max 实特征值 = 1（精确取到，来自不动点方向）；PSD 收缩类 5000 实例
   max 实特征值 = 1.000000000000。
3. 本定理不排除：(i) 跨模式无限切换导致的增长（JSR>1 或可实现扩张周期轨道）；
   (ii) μ=1 的 Jordan 块多项式增长；(iii) 非二次目标。见 research/04 义务清单更新。
4. 证明关键不等式 ‖Tv‖²≤⟨Tv,v⟩ 就是"T 为对称 PSD 收缩"的变体；对非对称或非 PSD
   的线性化（如 CHYY 的一般 C），该结构失效——与 CHYY 反例存在一致。
