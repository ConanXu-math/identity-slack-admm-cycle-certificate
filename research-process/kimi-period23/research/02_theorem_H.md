# 定理 H：齐次零目标松弛三块 ADMM 的迭代矩阵非扩张性

日期：2026-07-22。状态：**严格结论**（证明完整，数值独立核验通过）。

## 设定

问题（P）取 f≡0, g≡0, X=R^{n1}, Y=R^{n2}, b=0（均为合法：零函数适当闭凸，全空间闭凸）。
子问题解选择：最小范数最小二乘解（唯一，良定义）。
记 P := P_{range A}, Q := P_{range B}（正交投影）。由研究笔记 01 §5，迭代在状态
(p, t) ∈ range(Q) × R^m（p = By, t = z + λ/β）上是正齐次分段线性映射；
固定符号模式 σ（D_+ = diag(1[t_i>0]), D_- = I − D_+）后线性：

  a  = −P(p + D_+ t)
  p' = −Q(a + D_+ t)
  t' = D_- t − a − p'

记该线性映射为 M_σ（限制在 range(Q)×R^m 上；在 R^m×R^m 上延拓只多出零特征值）。

## 定理 H

对任意正交投影 P, Q 与任意 0/1 对角阵 D_+，M_σ 的每个特征值 μ 满足 |μ| ≤ 1。

## 证明

设 (p, t) ≠ 0 为特征对，μ ∉ {0, 1}（μ∈{0,1} 已满足结论）。特征方程：
(2) μp = −Q(a + D_+ t)
(3) μt = D_- t − a − μp
由 (3)：a = D_- t − μt − μp。令 u := p + t。
a + D_+ t = t − μu，代入 (2)：
  μ(p) = −Q(t − μu) ⟺ μ(I−Q)u = (μI−Q)t.   (B)
又 p + D_+t = u − D_-t，而 −P(p+D_+t) = a = D_-t − μu：
  P(u − D_-t) = μu − D_-t ⟺ (μI − P)u = (I−P)D_-t.   (A)
对 (A) 左乘 P：左端 P(μI−P)u = (μ−1)Pu，右端 P(I−P)D_-t = 0，因 μ≠1 得 **Pu = 0**；
于是 (A) 化为 μu = (I−P)D_-t。
对 (B) 左乘 Q：0 = (μ−1)Qt，因 μ≠1 得 **Qt = 0**；于是 (B) 化为 μ(I−Q)u = μt，即 **t = (I−Q)u**。
合起来：
  μu = (I−P)D_-(I−Q)u =: Su,   u ∈ ker P,  u ≠ 0
（u=0 ⇒ t=0, p=0，与特征向量非零矛盾）。
范数估计（正交投影与 0/1 对角阵范数 ≤ 1）：
  |μ|·‖u‖ = ‖Su‖ ≤ ‖D_-(I−Q)u‖ ≤ ‖(I−Q)u‖ = ‖t‖ ≤ ‖u‖,
最后一步因 u = Qu + Q^⊥u = p + t 为正交分解（p = Qu, t = Q^⊥u），‖u‖²=‖p‖²+‖t‖²。
故 |μ| ≤ 1。∎

## 推论与注记

1. **CHYY 型几何发散在松弛结构中不可能**：任何"轨道始终停留在固定符号锥内"的几何扩张
   （|μ|>1 的自洽特征方向）都不存在。一般三块 ADMM 的发散机制（CHYY 2016 反例）
   被 [A,B,I] + δ_+ 结构排除。
2. 证明只用 D_- 是对角收缩（d_i∈[0,1]），对"光滑化投影"同样成立。
3. 该定理**不排除**：(i) 单位圆上特征值的非平凡 Jordan 块（多项式增长）；
   (ii) 跨模式切换导致的发散（切换系统即使每个矩阵收缩也可能发散）；
   (iii) 非齐次/非二次目标的情形。这些是公开的证明义务（见研究笔记 03）。
4. 推广：f = δ_{X0}, g = δ_{Y0}（子空间指示函数）时，c ↦ Ax' 仍是到 A(X0) 的正交投影，
   定理 H 原样成立（仿射平移只加常数项，线性部分不变）。
5. 数值核验：exp2（~10 万随机实例全部 ρ=1.000000000）与 exp2b（特征值双射核验）。
   二次目标（T_A, T_B 为一般对称 PSD 收缩而非投影）**不在**本定理覆盖范围内：
   证明中 (A)⇒Pu=0 一步依赖 P²=P 的投影性，对一般 PSD 收缩失效。
